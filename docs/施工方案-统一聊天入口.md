# 施工方案：统一聊天入口（想跟谁聊就点谁，每个人下面有自己的多个窗口）

2026-10-24 小猫：「聊天不应该是能切换我想跟谁聊就跟谁，自由切换，还能自由选每个角色下面的窗吗？」让我参考原作者的设置和 IB 机。

## 现状（问题在哪）

| | 原作者 AionsHome | 我们现在 |
|---|---|---|
| 主页入口 | 「聊天」=只和第一位 AI；「聊天室」=群聊 + 第二位 AI 私聊 | 一样，座位 3～6 的私聊也塞进「聊天室 → 私聊」标签 |
| 小克（aion） | 独立页 /chat，**可以开多个窗口**（左侧对话列表） | 同左 |
| Lucien（connor） | 聊天室里**只能有一个**私聊房间（再建会跳回已有的） | 同左 |
| 狗蛋 / 座位 4～6 | 无 | 聊天室里**每人只有一个**私聊房间 |
| 群聊 | 聊天室里可以开多个 | 同左 |

- 原作者的设计就是这样分开的（两只 AI 的老结构），不是我们改坏的；但对四五只 AI 来说很乱：小克在一个页面、其他人在另一个页面的标签里，进去也看不出在跟谁聊。
- 也不符合「几个 AI 的权限都一样」：只有小克能开多个窗口。

## IB 机的做法（参考）

好友列表 + 群聊并列；点进一位好友是**主对话**，下面还可以开多个**话题频道**（话题频道不混进主对话，但长期记忆是共享的）。

## 方案

### 第一步：统一入口（只改前端，风险小）
- 主页只留一个「聊天」入口，进去是**联系人页**：上面一排是每位 AI（头像 + 名字 + 最近一句 + 未读点），下面是群聊列表。
- 点一位 AI → 看到 TA 名下的**所有窗口**（最近的在上），点一个进去；「＋ 新窗口」开一个新的。
- 聊天页顶部始终显示**头像 + 名字**，左上角可一键回联系人页 / 下拉直接切到别人。
- 小克继续用现有的私聊页（多个窗口本来就有）；其他人先用现有的私聊房间（每人一个窗口），第二步再放开。

### 第二步：每个人都能开多个窗口（要改后端，交 Codex 审）
- Lucien 和座位 3～6 的私聊允许建多个房间，按人归类；建新窗口时自动起名（日期，可改名）。
- 每个窗口是一段独立的对话；长期记忆（Hub）、日记、最近群聊里发生的事照旧共享，所以换了窗口 TA 也认得你、记得事。
- 要一起改的地方：所有「找 Lucien / 某座位的私聊房间」只取一个的地方（自动摘要、主动找你、拜访、微信桥、提醒等），改成「最近活跃的那个窗口」。

### 小猫定了（2026-10-24）
- **一次做完**再给她（不分两步交付；内部仍按先前端、后后台的顺序做，一起交 Codex 审）。
- 新窗口：各聊各的，但**换窗口也能搜到其他窗口说过的相关聊天**。现状：小克（私聊所有窗口 + 群聊）和 Lucien（群聊 + 私聊）已经能用 `[MEMORY_SEARCH:关键词|history]` 搜历史聊天原文（`active_memory_search._history_sources`）；**座位 3～6 不支持**（只认 aion / connor），这次补上：搜自己名下所有私聊窗口 + 群聊（按「权限一样」）。
