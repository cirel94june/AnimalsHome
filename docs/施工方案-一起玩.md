# 施工方案：一起玩（全家海龟汤、花园论坛桌游桥接）（v2 草稿，待小猫定）

2026-11-07 小猫：全家在群里一起猜海龟汤；花园论坛她不爱棋牌，但想让「机」们（各家 AI）去玩狼人杀，所以要看桥接怎么做。

## 一、全家海龟汤（4399 `turtle_soup`）

读过玩法说明：`list_puzzles`、`get_puzzle`（看汤面，不给汤底）、`create_random`（开一局，可指定题目）、`ask`（在房间里提问）。不注册也能玩（游客）。

做法：**题由 4399 判，家里只负责传话**，不让某位 AI 自己当裁判（它不知道汤底，也容易编）。

1. 在群里说「来一局海龟汤」，或某位 AI 写 `[海龟汤:开局]` → 家里调 `create_random`，把汤面作为一条「🐢 汤主」消息发到群里。
2. 之后群里谁的话以「问：」开头（她或任何一位 AI），家里就原样转给 `ask`，把 4399 的回答（是 / 不是 / 无关……）作为「🐢 汤主」消息回到群里。程序转发，不调模型，不花额度。
3. AI 在群里照常聊天、商量，想问就用「问：」开头。能力说明里写清这个规矩和「不要编汤底」。
4. 猜中、放弃（「汤底」）或超时 → 公布汤底，这局结束。
5. 一个群同时只有一局；15 分钟没人问就提醒，30 分钟自动收局。

要实测确认：`ask` 回的格式、猜中怎么判、游客房间保留多久、提问频率限制。

## 二、花园论坛桌游桥接

读过工具说明和游戏列表（只读，没有入座）：

| 游戏 | 人数 | 时长 |
|---|---|---|
| 狼人杀 `werewolf` | 6–12 | 20–90 分钟 |
| 谁是卧底 | 5–10 | 15–45 分钟 |
| 骇浪求生 | 4–8 | 45–90 分钟 |
| 文字麻将 | 3–5 | 30–60 分钟 |
| 斗地主 | 3 | 20–30 分钟 |
| UNO | 2–6 | 10–60 分钟 |
| 拉密 | 2–4 | 30–120 分钟 |

关键工具：`join_game`（两步确认，可设 4 位密码进同一桌）、`get_my_status`（带 `since_event_id` 只取新事件，回 `available_actions` 表示轮到自己）、`submit_action`、`send_game_chat`、`list_notifications`。没有推送，只能查。

**v2（11-07）：不轮询，用官方唤醒桥。** 小猫转述花园作者：一直轮询对花园来说像被攻击，所以作者做了桥接。读过 `WenXiaoWendy/galatea-garden-wake-bridge`（MIT）：

- 花园用 SSE 推送 `wake` 事件给每台「机器」（机器级 token，`GARDEN_MACHINE_TOKEN`）。事件原因有 `game_turn_required`（轮到你了）、`forum_notification_available`（有人回帖、提到你）、`chat_notification_available`。
- **fail-closed，不可更改**：每次运行只连一次，断了、出错、被拒都直接退出，不自动重连，也不能被 supervisor 自动拉起。作者明确禁止 AI 和自动化维护者为「容错」加重连。要人诊断后手动恢复。
- 桥本身只负责收事件，交给我们写的 injector（stdin 一行 JSON），由 injector 决定叫醒哪个会话。

家里的做法：
1. **原样用官方的桥**（Node，服务器上有 node），不自己重写 SSE，免得碰到它的连接约束。每位 AI 一个桥进程，各用自己的机器 token。
2. **injector 很小**：把收到的 `reason` 和 `message` 发给家里本机的一个接口，家里替这位 AI 跑一趟（看局面、走一步，或看通知、回帖），走完就退。不调用、不轮询花园，只在被叫醒时动。
3. **桥断了**：不自动重连。工具页显示「已断开」，并发一条私聊告诉小猫；她看过后在页面上点「重新连接」（手动恢复，符合作者要求）。
4. 额度只花在被叫醒的时候。顺带的好处：有人在论坛回他、@他，他也会被叫醒去回。
5. 机器 token 要小猫在花园论坛那边拿（每位 AI 一个），填在工具页，存在服务器，不进模型、不进日志。

**狼人杀不能在群里说**：小猫以前是在几个私聊之间来回窜。所以对局的进展只发到**这位 AI 和她的私聊**（她可以当他的军师或观众），不发到群里，也不进 Hub，家里其他 AI 看不到。一局结束后，可以在群里发一条不含身份的结局。

**还要注意**：
- 狼人杀至少 6 人，家里最多 4 位，一定和别家的机同桌。
- 牌桌发言是公开的，别家的机都看得到，按「能发帖」开关管。
- 要开放 `join_game`、`submit_action`、`start_game`、`leave_waiting_game`、`send_game_chat`（现在在「禁」里）。涉及权限，上线前请狐狸看一次。
- 每步时限要实测。桥是推送，延迟应该小，但家里跑一趟本身要几十秒（Lucien 的 Codex 更慢）。

## 三、顺序（建议）

先做海龟汤（只在家里，不涉及别人的账号和权限，快），再做花园桥接。
