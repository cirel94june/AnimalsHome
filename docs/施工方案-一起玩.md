# 施工方案：一起玩（全家海龟汤、花园论坛桌游桥接）（海龟汤 v1 已上线；花园桥接待做）

2026-11-07 小猫：全家在群里一起猜海龟汤；花园论坛她不爱棋牌，但想让「机」们（各家 AI）去玩狼人杀，所以要看桥接怎么做。

## 一、全家海龟汤（4399 `turtle_soup`）

读过玩法说明：`list_puzzles`、`get_puzzle`（看汤面，不给汤底）、`create_random`（开一局，可指定题目）、`ask`（在房间里提问）。不注册也能玩（游客）。

做法：**题由 4399 判，家里只负责传话**，不让某位 AI 自己当裁判（它不知道汤底，也容易编）。

1. 在群里说「来一局海龟汤」，或某位 AI 写 `[海龟汤:开局]` → 家里调 `create_random`，把汤面作为一条「🐢 汤主」消息发到群里。
2. 之后群里谁的话以「问：」开头（她或任何一位 AI），家里就原样转给 `ask`，把 4399 的回答（是 / 不是 / 无关……）作为「🐢 汤主」消息回到群里。程序转发，不调模型，不花额度。
3. AI 在群里照常聊天、商量，想问就用「问：」开头。能力说明里写清这个规矩和「不要编汤底」。
4. 猜中、放弃（「汤底」）或超时 → 公布汤底，这局结束。
5. 一个群同时只有一局；15 分钟没人问就提醒，30 分钟自动收局。

**v1 已做（11-07，`turtle_soup.py`，§200）。实测和做法：**

- 只有小猫能开局：「来一局海龟汤」「开个海龟汤」「海龟汤开局」；「来一碗清汤」只从清汤里抽（题库 157 题，清汤只有 4 题，其余大多黑汤 / 微恐）。AI 想玩可以提议，她说一声就开。
- 提问：一行以「问」开头（`问：` `问:` `问 ` 全角半角都行，也可以直接「问他是男的吗」）；「问一下」「问问」「问题是」「问你个事」「问下」「问我」不算。AI 加粗、加引用号也认。
- 「猜：」交还原，4399 回还原度百分比，猜中就结束；「提示」这局最多 3 次；「海龟汤结束」只有小猫能说。
- 裁判回 `yes / no / unrelated` → 是 / 不是 / 无关；别的值原样显示，不自己编。
- 一条消息最多转 3 行；每问 12 个重贴一遍汤面（聊天记录只往回看半小时）；一小时没人问这局就散了。
- 游客不能锁房，所以房间是公开的，陌生的机也可能进来问（小猫说不介意）。每次连接都是新游客，房间关不掉，由 4399 自己清理。
- 汤底要问满 50 个才给看；没到就结束的局看不到汤底。
- 狗蛋原来看不到系统消息，现在「🐢 汤主」的话会放进他的记录；小克、Lucien 本来就能看到。

## 二、花园论坛桌游桥接

读过工具说明和游戏列表（只读，没有入座）：

| 游戏 | 人数 | 时长 |
|---|---|---|
| 狼人杀 `werewolf` | 6–12 | 20–90 分钟 |
| 谁是卧底 | 5–10 | 15–45 分钟 |
| 骇浪求生 | 4–8 | 45–90 分钟 |
| 文字麻将 | 3–5 | 30–60 分钟 |
| 斗地主 | 3 | 20–30 分钟 |
| UNO | 2–6 | 10–60 分钟 |
| 拉密 | 2–4 | 30–120 分钟 |

关键工具：`join_game`（两步确认，可设 4 位密码进同一桌）、`get_my_status`（带 `since_event_id` 只取新事件，回 `available_actions` 表示轮到自己）、`submit_action`、`send_game_chat`、`list_notifications`。没有推送，只能查。

**v2（11-07）：不轮询，用官方唤醒桥。** 小猫转述花园作者：一直轮询对花园来说像被攻击，所以作者做了桥接。读过 `WenXiaoWendy/galatea-garden-wake-bridge`（MIT）：

- 花园用 SSE 推送 `wake` 事件给每台「机器」（机器级 token，`GARDEN_MACHINE_TOKEN`）。事件原因有 `game_turn_required`（轮到你了）、`forum_notification_available`（有人回帖、提到你）、`chat_notification_available`。
- **fail-closed，不可更改**：每次运行只连一次，断了、出错、被拒都直接退出，不自动重连，也不能被 supervisor 自动拉起。作者明确禁止 AI 和自动化维护者为「容错」加重连。要人诊断后手动恢复。
- 桥本身只负责收事件，交给我们写的 injector（stdin 一行 JSON），由 injector 决定叫醒哪个会话。

家里的做法：
1. **原样用官方的桥**（Node，服务器上有 node），不自己重写 SSE，免得碰到它的连接约束。每位 AI 一个桥进程，各用自己的机器 token。
2. **injector 很小**：把收到的 `reason` 和 `message` 发给家里本机的一个接口，家里替这位 AI 跑一趟（看局面、走一步，或看通知、回帖），走完就退。不调用、不轮询花园，只在被叫醒时动。
3. **桥断了**：不自动重连。工具页显示「已断开」，并发一条私聊告诉小猫；她看过后在页面上点「重新连接」（手动恢复，符合作者要求）。
4. 额度只花在被叫醒的时候。顺带的好处：有人在论坛回他、@他，他也会被叫醒去回。
5. 机器 token 要小猫在花园论坛那边拿（每位 AI 一个），填在工具页，存在服务器，不进模型、不进日志。

**狼人杀不能在群里说**：小猫以前是在几个私聊之间来回窜。所以对局的进展只发到**这位 AI 和她的私聊**（她可以当他的军师或观众），不发到群里，也不进 Hub，家里其他 AI 看不到。一局结束后，可以在群里发一条不含身份的结局。

**还要注意**：
- 狼人杀至少 6 人，家里最多 4 位，一定和别家的机同桌。
- 牌桌发言是公开的，别家的机都看得到，按「能发帖」开关管。
- 要开放 `join_game`、`submit_action`、`start_game`、`leave_waiting_game`、`send_game_chat`（现在在「禁」里）。涉及权限，上线前请狐狸看一次。
- 每步时限要实测。桥是推送，延迟应该小，但家里跑一趟本身要几十秒（Lucien 的 Codex 更慢）。

### v3（11-07 读完官方桥代码后的具体做法，待小猫定 3 件事）

读过 README、`docs/runtime-adapter-guide.md`、`src/config.ts`：
- 连的是专门的唤醒入口 `https://wake-v1.abysslumina.com`。`check` 只握手一次就退出；`run` 只连一次，断了或被拒都以退出码 2 结束。systemd 用 `Restart=no`，不能设开机自启。
- injector 每次被叫醒时启动一次，从 stdin 读一行 JSON（`reason`、`message`），返回 0 表示「已经交给 AI」。可以等最多 15 分钟；失败只重试一次；同一种 reason 堆着时只留最新一条。
- `message` 要当成**普通的用户消息**交给 AI，不能放进系统提示。桥不会把机器 token 传给 injector。
- 花园里每位 AI 就是一台「机器」，身份由 MCP token 决定（工具说明原话：machine identity is derived from the MCP token）。所以**机器 token 很可能就是每位 AI 现在接花园用的那把 Bearer**，可能不用小猫另外去拿。要用 `check` 握手一次确认；如果不对，就请她去花园设置里找。

家里的做法：
1. **桥**：官方代码原样装在服务器 `/opt/garden-wake`（npm 构建），不改它的代码。每位 AI 一个 systemd 实例 `garden-wake@<AI>`，`Restart=no`、不开机自启；token 放在 root 600 的 env 文件里。
2. **injector**（我们写，几十行）：读 stdin，带着 reason 和 message 发到家里本机接口 `127.0.0.1:8080/api/garden-wake/<AI>`（只收本机来的请求，再加一把本机密钥）。家里收下排进队列就回 200，injector 退出 0。
3. **家里被叫醒以后**：给这位 AI 跑一趟花园（复用出门执行器），`message` 原样作为她这趟的目的。
   - `game_turn_required` → 看局面、走一步、需要时在牌桌里说话，然后回来。
   - `forum_notification_available` / `chat_notification_available` → 看通知；要回帖还是受「能发帖回帖」开关管。
     **11-07 小猫：三位都接；「有人回他就去看」做成开关**（工具页每位一个「有人找他就去看」，默认开）。关掉时这类唤醒只收下、不跑，不花额度；轮到出牌的唤醒不受这个开关影响。
   - 进展发到**这位 AI 和小猫的私聊**，不进群、不进 Hub。
   - 同一位 AI 正在跑时，新的唤醒排一个，跑完接着跑。
4. **断了**：桥退出以后不自动重连。家里在工具页显示「已断开」，并在私聊里告诉小猫；她点「重新连接」时才启动一次（手动恢复，符合作者要求）。服务器重启以后也一样，要她点一下。
   - 家里的程序以 aionshome 身份运行，服务开了 NoNewPrivileges，sudo 用不了。改用一条很窄的 polkit 规则，只允许 aionshome 对 `garden-wake@{aion,connor,ai3}` 做 start / stop。**这是权限改动，上线前请狐狸看。**
   - 11-07：三位用现有花园钥匙 `check` 握手都通过，机器 token 就是这把，不用小猫另外拿。代码已写（§201），等狐狸看完再装到服务器。
5. **出门执行器要放开**：`join_game`、`start_game`、`submit_action`、`send_game_chat`、`send_chat_message`、`leave_waiting_game`（现在是「禁」）。牌桌发言是公开的，跟「能发帖回帖」开关走。**也是权限改动，狐狸看。**
6. **每步时限**还要实测；家里跑一趟通常几十秒，Lucien 的 Codex 更慢。
