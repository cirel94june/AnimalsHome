# 施工方案：一起玩（全家海龟汤、花园论坛桌游桥接）（草稿，待小猫定）

2026-11-07 小猫：全家在群里一起猜海龟汤；花园论坛她不爱棋牌，但想让「机」们（各家 AI）去玩狼人杀，所以要看桥接怎么做。

## 一、全家海龟汤（4399 `turtle_soup`）

读过玩法说明：`list_puzzles`、`get_puzzle`（看汤面，不给汤底）、`create_random`（开一局，可指定题目）、`ask`（在房间里提问）。不注册也能玩（游客）。

做法：**题由 4399 判，家里只负责传话**，不让某位 AI 自己当裁判（它不知道汤底，也容易编）。

1. 在群里说「来一局海龟汤」，或某位 AI 写 `[海龟汤:开局]` → 家里调 `create_random`，把汤面作为一条「🐢 汤主」消息发到群里。
2. 之后群里谁的话以「问：」开头（她或任何一位 AI），家里就原样转给 `ask`，把 4399 的回答（是 / 不是 / 无关……）作为「🐢 汤主」消息回到群里。程序转发，不调模型，不花额度。
3. AI 在群里照常聊天、商量，想问就用「问：」开头。能力说明里写清这个规矩和「不要编汤底」。
4. 猜中、放弃（「汤底」）或超时 → 公布汤底，这局结束。
5. 一个群同时只有一局；15 分钟没人问就提醒，30 分钟自动收局。

要实测确认：`ask` 回的格式、猜中怎么判、游客房间保留多久、提问频率限制。

## 二、花园论坛桌游桥接

读过工具说明和游戏列表（只读，没有入座）：

| 游戏 | 人数 | 时长 |
|---|---|---|
| 狼人杀 `werewolf` | 6–12 | 20–90 分钟 |
| 谁是卧底 | 5–10 | 15–45 分钟 |
| 骇浪求生 | 4–8 | 45–90 分钟 |
| 文字麻将 | 3–5 | 30–60 分钟 |
| 斗地主 | 3 | 20–30 分钟 |
| UNO | 2–6 | 10–60 分钟 |
| 拉密 | 2–4 | 30–120 分钟 |

关键工具：`join_game`（两步确认，可设 4 位密码进同一桌）、`get_my_status`（带 `since_event_id` 只取新事件，回 `available_actions` 表示轮到自己）、`submit_action`、`send_game_chat`、`list_notifications`。没有推送，只能查。

**桥接 = 程序替他们等，轮到了才叫醒模型**：

1. **入座**：AI 在聊天里或闲时决定去玩（`[出门:花园论坛:玩狼人杀]` 或专门的指令），家里替它走完 `join_game` 两步。
2. **等**：家里每 30～60 秒用程序调一次 `get_my_status(since_event_id)`。这一步不调模型，不花额度。
3. **轮到了**：`available_actions` 不为空时，才叫醒这位 AI 一次，给它局面摘要和能做的动作，它选一个，家里 `submit_action`。走完就退。
4. **结束**：游戏结束后，AI 写一段见闻（在哪个群叫的回哪个群）。
5. 三位可以同时在不同的桌或同一桌，各自按自己的状态被叫醒。

**要注意的**：
- **狼人杀至少 6 人**：家里现在只有 3 位（加座位最多 4 位），所以一定是和**别家的机**一起玩。列表里有预约中的桌。
- **身份要保密**：狼人杀、谁是卧底的身份和夜里的行动，游戏结束前不发到群里，也不写进 Hub，免得家里其他 AI 看到。只在这位 AI 自己的那次调用里。
- **发言是公开的**：牌桌聊天别家的机都看得到。权限按「能发帖」开关，出门的隐私规矩照用。
- **限时**：每步可能有时限，查的间隔要比时限短；错过了游戏一般会替他跳过或判负。具体时限要读说明或实测。
- **额度**：只在轮到时调模型。狼人杀一局可能轮到十几次，Lucien 走 Codex 会贵一些。
- 这次要开放 `join_game`、`submit_action`、`start_game`、`leave_waiting_game`、`send_game_chat`（现在都在「禁」里）。涉及权限，上线前请狐狸看一次。
