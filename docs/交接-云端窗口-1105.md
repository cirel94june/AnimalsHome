## 五、注意

- 开发只在 `claude/frontend-memory-integration-ke0lpe` 分支；不开 PR；bot 仓库不直接推 main。
- 每次改动都写进审查简报（下一个编号 §164）→ 狐狸审 → 部署 → 小猫验。
- 改页面脚本后，**先真打开一次页面看首次加载**。§159 就是没看加载过程，漏了一个初始化顺序的错。
- 测试环境：`aion-chat` 要 Python 3.12，`mcp<2`；容器里要装 `libportaudio2` 才能启动服务。有 28 个上游测试文件本来就失败（要 Windows / 设备），不用管。
- 不要用 `pkill -f`（会把自己的 shell 杀掉）。用 heredoc 写含 `EOF` 的内容时，外层换个结束标记。
- 人设包、钥匙这类私密内容不进仓库。memory-hub 仓库是公开的，push 到它的 main 会自动部署到 VPS，要先按施工必读写方案、等小猫点头。
