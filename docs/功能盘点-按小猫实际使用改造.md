# 功能盘点：按小猫的实际使用逐项改造

> AionsHome 是开源项目，很多设置是原作者自己的（人物、设备、账号、地址）。
> 这份清单把桌面上每个 app 和 AI 的自主活动过一遍：做什么、搬到服务器（VPS）后能不能用、按小猫的用法要怎么改。
> 「问」= 需要小猫回答；「定」= 小猫已经确认的做法。确认后按顺序施工，进度记在最后一节。

## 一、总的方向（小猫 2026-10-10 确认）

- 最终形态：**安卓 APK**，连服务器上的 AionsHome；MCP 由服务器去连，手机只是界面。
- 每个功能都要按小猫的实际使用改，不照搬原作者的设置。
- Lucien：**保留 Codex 接口，同时要能走 API**（聊天室设置里已经能给他选 API 模型；要核对其他功能里写死 Codex 的地方）。
- AI 自主活动要能：去论坛玩、自主用浏览器、去游戏网站玩、旅行、自己看看 GitHub……

## 一b、小猫的决定（2026-10-10）

本地记忆保留做**备用**：Hub 连不上时兜底、归巢（离线）模式用，以及依赖它的功能（翻旧记忆、记忆库页面）先不动。
具体怎么分工（本地还要不要每 30 分钟自动总结）要先查清依赖再定，列入施工顺序。

### Hub R2 已上线（2026-10-12）：回望页可直接接

- 这一轮想起了什么：`context(incremental)` 返回的 `metadata.recalled`（id、reason、preview），`metadata.near_misses`（差一点的和原因，含「你标过不相关」「多次标过不相关」）。
- 「不相关」：`POST /api/recall/feedback`，body `{"memory_id", "query"（当时小猫那句话）, "ai_id"}`，Bearer HUB_SECRET，返回 `feedback_id`；撤销 `DELETE /api/recall/feedback/{feedback_id}`。
