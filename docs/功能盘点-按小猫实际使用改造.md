# 功能盘点：按小猫的实际使用逐项改造

> AionsHome 是开源项目，很多设置是原作者自己的（人物、设备、账号、地址）。
> 这份清单把桌面上每个 app 和 AI 的自主活动过一遍：做什么、搬到服务器（VPS）后能不能用、按小猫的用法要怎么改。
> 「问」= 需要小猫回答；「定」= 小猫已经确认的做法。确认后按顺序施工，进度记在最后一节。

## 一、总的方向（小猫 2026-10-10 确认）

- 最终形态：**安卓 APK**，连服务器上的 AionsHome；MCP 由服务器去连，手机只是界面。
- 每个功能都要按小猫的实际使用改，不照搬原作者的设置。
- Lucien：**保留 Codex 接口，同时要能走 API**（聊天室设置里已经能给他选 API 模型；要核对其他功能里写死 Codex 的地方）。
- AI 自主活动要能：去论坛玩、自主用浏览器、去游戏网站玩、旅行、自己看看 GitHub……

## 一b、小猫的决定（2026-10-10）

**总原则：所有接入的 AI 都能做这些**（不再只有主 AI / 第二 AI 两位）。

**记忆库主次（Claude 建议，2026-10-10）**：以 Memory Hub 为主。它是所有端（TG、官方客户端、AionsHome）共用的一份记忆，
有人设/隐私隔离和每晚整理；本地记忆只覆盖 AionsHome 自己，两边都提取会重复、还可能互相矛盾。
本地记忆保留做**备用**：Hub 连不上时兜底、归巢（离线）模式用，以及依赖它的功能（翻旧记忆、记忆库页面）先不动。
具体怎么分工（本地还要不要每 30 分钟自动总结）要先查清依赖再定，列入施工顺序。

## 二、搬到服务器后的硬限制

| 类别 | 说明 |
|---|---|
| 需要 Windows 电脑本机 | 电脑活动监测（activity）、电脑屏幕截图、接在电脑上的摄像头、Gemini CLI / Codex CLI 这类「电脑上登录的程序」 |
| 需要手机 App | 手机摄像头、通知读取、手环/戒指、定位、红外抱枕、应用监管（无障碍）——装 APK 后由手机上报，服务器能收到 |
| 需要第三方账号 | 淘宝、小红书、瑞幸、网易云、高德、硅基流动、Gemini 等，要换成小猫自己的账号/Key |

## 四、AI 自主活动

现有（只有前两位 AI 有，Jasper 还没有）：主动找你聊天、上网冲浪（搜索，不是真的开浏览器）、
看小红书、逛淘宝、去朋友家串门、看留言板、翻相册、翻旧记忆、看许愿池、和 Seeky 互动、和另一位 AI 聊天、看家庭动态。

小猫想要的，对应情况：

| 想要 | 现在有什么 | 要做什么 |
|---|---|---|
| 去论坛网站玩 | 娱乐室默认接了「AI小镇」MCP，但只在娱乐室里、由你下指令时用 | 接小猫的论坛 MCP，并加成 AI 能自己决定去的自主活动 |
| 自主用浏览器 | 只有「上网冲浪」（搜索 + 读网页摘要） | 新做：接浏览器类 MCP（能点开网页、翻页） |
| 去游戏网站玩 | 娱乐室可以接 | 同论坛 |
| 旅行 | 有「探索旅程」的框架（autonomy_journey） | 接小猫的旅行 MCP / 目的地 |
| 看 GitHub | 没有 | 新做：GitHub 只读浏览（或 MCP） |
| 其他 MCP 工具 | 娱乐室里能接，平时聊天用不到 | 定：哪些工具平时聊天也要能用 |

问：每个 MCP 的名字、网址（或接入说明），以及希望 AI 是「自己有空时去玩」还是「聊天时也能用」。
