# 施工方案：不用 Tailscale 也能安全打开 AionsHome（草稿，待小猫选）

2026-10-23 小猫：Tailscale 和 VPN 只能开一个，而且 Tailscale 走中转慢（下 30M 安装包用了 6 小时）。想不用 Tailscale。

## 现状

- AionsHome 自己**没有登录**，只监听 127.0.0.1:8080，靠 `tailscale serve`（8443）只对小猫的设备开放；`AIONSHOME_TRUST_TAILSCALE=1`。`security_access` 只做「新设备 / 新 IP 提醒」，不是门锁。
- 手机上 Android 只能同时开一个 VPN 类应用，Tailscale 和翻墙 VPN 互斥。
- Tailscale 慢：手机和 VPS 打不通直连，走 DERP 中转。
- 定位、手机截屏、推送等都需要手机连得上服务器；关掉 Tailscale 后这些都断了（定位配置和记录目前为空）。
- 服务器上已有 Caddy + 免费动态域名 `xiaokememory.camdvr.org`（给 Hub 用）。
- **原作者的远程方案是 Cloudflare**：Cloudflare Tunnel + Cloudflare Access（登录页在 cloudflareaccess.com），App 里已有配合代码（`ConnectionEndpoint.CLOUDFLARE_HOST`、`CloudflareReauthState`），只是域名是占位的 `chat.example.com`，要换成真实域名重新打包 App。

## 两条路

### A：Cloudflare（原作者的路，推荐）
- 要做：小猫买一个自己的域名（一年约几十到一百元人民币），交给 Cloudflare 托管（免费）；服务器装 `cloudflared` 建隧道（约 30MB 内存，不用开放任何端口）；Cloudflare Access 设成只允许小猫的邮箱登录（收验证码或 Google 登录），登录一次记住一段时间。
- AionsHome：几乎不用写登录代码（门锁由 Cloudflare 负责，经过大量验证）；App 把域名改成小猫的、重新打包。
- 好处：最安全、最省事；不用 VPN 也行（取决于所在网络能不能顺畅连 Cloudflare，开着 VPN 一定没问题）；不跟 VPN 冲突。
- 代价：要买域名；第一次配置 Cloudflare 需要小猫登录 Cloudflare 账号点几下（我一步步带）。

### B：AionsHome 自己加登录 + 现有免费域名
- 要做：Caddy 加一个子域名（如 `home.xiaokememory.camdvr.org`）指向 AionsHome；AionsHome 加登录页（密码 + 记住设备的长期登录、连续输错锁定、新设备登录提醒），所有页面和接口（含 WebSocket、上传、手机 App 的接口）都要先登录；App 打包时改成这个地址。
- 好处：不花钱。
- 代价：门锁是我们自己写的，要非常仔细（Codex 重点审）；免费动态域名稳定性一般。

### 共同点
- 换好之前 **不关 Tailscale**；新门锁装好、确认手机 App 能用后，Tailscale 留作备用或停掉都行。
- 手机连上之后，定位、截屏、推送会恢复；定位还需要在设置里打开位置追踪、填高德 Key。
