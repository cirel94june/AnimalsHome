# 施工方案：共读学习角（③）

2026-10-21 小猫的要求：
- 共读：分享网页、微信读书里的书、屏幕上正在看的。
- 学习：陪读一段外语、练口语、解释单词 / 句式 / 语法；讲题、出题提问。
- 大家都在（小克、Lucien、启用的座位）。

## 思路：一个「学习模式」的群聊

不新造房间类型（群聊相关的过滤、合并时间线、Hub 范围都按 `group` 判断，新类型容易漏）。做法是**普通群聊 + 学习标记**：

- 新表 `study_rooms(room_id, material, material_title, material_source, updated_at)`。有这条记录的群就是「共读学习角」，大家照常在群里回复。
- 进这个群时，每位 AI 的上下文里多一段：
  1. **学习角说明**：这里是共读学习角，大家一起读材料；小猫问单词、句式、语法时讲清楚，给例句；外语段落可以带读、逐句解释；她要练口语时用对应语言陪她对话并温和纠错；讲题先引导思路，出题时一次一道，等她答完再讲。几个人都在，不要重复别人刚讲过的，可以补充或换个角度。
  2. **当前材料**（如果有）：标题、来源、正文（截断到合适长度，比如 6000 字）。
- 隐私规则照群聊口径（`group_privacy_rule`）。

## 分段

- **A 房间 + 网页材料**（先做）
  - 聊天室里新建「共读学习角」（就是带学习标记的群，大家都在）。
  - 侧边「材料」面板：贴网址 → 服务器用已有的网页提取（Tavily extract）取正文 → 存成当前材料，房间里显示「📖 换了一份材料：标题」。也可以直接粘贴一段文字当材料（外语短文常用）。
  - 三条 AI 路径（小克群聊、Lucien 群聊、座位群聊）都注入学习说明 + 材料。
- **B 看屏幕**
  - 学习角输入框旁加「看看我的屏幕」：复用悬浮窗的截屏（`/api/floating-chat/screen`），截图作为这条消息的附件发出，大家都能看到。
- **C 微信读书**
  - 用小猫给的微信读书指令工具（书架、划线、笔记）。在材料面板选一本书 → 把她在这本书里的划线和笔记导入成材料（看不到正文，只有她划过的句子和写的想法）。
  - 需要先确认工具的用法和 API key 放在服务器 data/ 里（不进仓库）。
- **D 口语和朗读**
  - 输入框的语音输入（已有的转写）在学习角默认打开；AI 回复里的外语句子可以点读（已有 TTS）。
  - 口语练习：她说一句，AI 先回应内容，再单独一行给出更地道的说法 / 纠错。

## 不改

- 普通群聊、私聊行为不变；没有学习标记的群不注入任何东西。
- 已有的「陪伴阅读」（EPUB 批注）和「英语角」（学习卡片）不动，以后可以把学习角里学到的单词存进英语角的卡片（另议）。
