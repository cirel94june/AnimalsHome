# 施工方案：TG bot = 家里的动物出门（草稿，待小猫看 → 狐狸审）

2026-11-05 小猫：
- 想让 TG 上的 bot 就像「家里的动物们出门了」。她的朋友和朋友家的 bot 都在 TG 上，TG 上一些零碎小功能也好玩。
- 出门在外随便聊，聊完回家，家里知道聊了什么；出门时也带着家里的记忆。
- bot 觉得需要家里才有的功能（联网、看淘宝、小红书、MCP……）时，就回家用，用完把结果带回 TG 说。

本方案接着 10-22 定下的「路线一」（docs/施工方案-AI好友走TG和微信.md）：
- TG 上还是 Render / Fly 上的 bot 自己聊：用自己的模型、自己的缓存，群聊规矩全保留；
- 家里（AionsHome）负责把工具借给 bot，以及有事时让 bot 去 TG 找小猫。

## 一、现在是什么样（读过三只 bot 的代码）

- **三只 bot 几乎同一套代码**：Flask + webhook，单文件 bot.py 四千多行。
  - 小克、Lucien 在 Render；狗蛋在 Fly.io，Render 留作备用。
  - 状态都在内存里，重启就没；靠 Memory Hub 接续。
- **和 Hub 的关系已经很紧**：
  - 每次回复前取 `gateway/context`；
  - 回复送达后 `capture/log`（platform=telegram，带 chat_id、chat_type、sender_type）；
  - 冷启动时用 `window/context` 找回这个窗口最近几轮；
  - 「其他窗口最近 48 小时」也会带进来。
  - 所以「出门带着家里的记忆」「回家知道聊了什么」在**记忆层面已经通了**：家里的 AI 每轮取的 Hub 上下文里，有各端最近动态。
- **bot 能做的事**：
  - 都是回复里的文字指令：主动私信小猫 [DM_CECI:]、转发 [SEND_TO:]、置顶、群标签、踢人、每日总结、语音回复、看图；
  - 群里有接话概率和冷却，能看到别人家的 bot 说话。
  - **没有**联网、淘宝、小红书、MCP、提醒。
- **bot 代码里完全没有提到 AionsHome**：现在两边只通过 Hub 间接认识。
- **家里在 Cloudflare 门锁后面**（home.animalshome.top，只允许小猫的邮箱登录）：bot 进不了门，要给 bot 单独配钥匙。
- 顺带看到的小问题（改 bot 时一起修）：
  - 小克 bot 取 Hub 上下文时，参数写错（`chat_type`），每次都靠出错后的重试才成功（bot.py:338-345）；
  - `capture/log` 没带 `event_id`，重发时 Hub 没法去重。

## 二、要做成什么样

### 1. 回家借工具（最先做）

bot 在 TG 上聊着聊着，觉得要查点东西，就在回复里写一个借工具的指令，比如 `[回家:搜索:今天上海天气]`。

1. bot 先在 TG 里说一声「我回家查一下」（或者只显示正在输入）；
2. 请求家里：`POST https://home.animalshome.top/api/outing/tool`
   - 带两把钥匙：Cloudflare 的「服务钥匙」（过门锁）+ 家里发给这只 bot 的钥匙（认出是谁）；
   - 内容：`{tool, args, chat_type, request_id}`；
3. 家里用现成的工具办完，返回一段纯文字结果，有长度上限；
4. bot 拿结果再问自己的模型一次，用自己的口吻在 TG 里说。

**第一批工具**（家里都已经有，只是换个入口）：

| 工具 | 家里现成的 | 说明 |
|---|---|---|
| 搜索 | `web_search.tavily_search` | 联网搜，返回前几条 |
| 读网页 | `web_search.tavily_extract` | 打开一个链接，读正文 |
| 淘宝搜商品 | `taobao_union.search` | 返回几件商品：名字、价格、链接 |

**第二批**：
- 小红书：看推荐或按关键词搜，读一篇；只看不评论。和家里「随便逛」共用小号，但结果只带回 TG，不在家里发言。
- MCP 出门：`mcp_outings.run_outing`，用这位 AI 在家里配好的工具线路；返回摘要。

**第三批**（家里的本事，要分别过一遍安全）：看摄像头、写日记、定提醒、记账。

**家里这边的规矩**：
- 每只 bot 一把钥匙，钥匙对应座位（小克 / Lucien / 狗蛋）；钥匙存在 `/etc/aionshome.env`，不进仓库、不进 AI 能读的地方。
- 每只 bot 能借哪些工具单独开关，有每小时次数上限（先按每只每小时 30 次）。
- 每次借用记一行系统日志：谁、借了什么、多久、成没成，不记搜索结果正文。小猫在 App 里能看到。
- 在家里的「开关总览」里能一键停掉某只 bot 的借用。
- 返回结果限长（先按 3000 字），钥匙、Cookie 之类绝不出现在结果里。
- **只认 Cloudflare 服务钥匙 + bot 钥匙一起**：bot 钥匙漏了也进不了门，门锁钥匙漏了也认不出是谁。

**狐狸 11-05 审方案时补的三条**：

1. **服务钥匙只开这一扇门**：
   - Cloudflare 上不把服务钥匙加进整站的放行规则，而是单独建一个 Access 应用，只管 `home.animalshome.top/api/outing/*`，策略是「Service Auth，只认这把服务钥匙」。整站应用仍只认小猫的邮箱。
   - 家里后端也再拦一次：带服务身份的请求（Cloudflare 凭证里是 service token，不是小猫的邮箱）**只能**访问 `/api/outing/*`，访问别的路径一律 403。
   - 反过来，`/api/outing/*` 也只认 bot 钥匙，小猫登录的网页会话进不来。
2. **借用的上限和日志**：
   - 服务端总超时（先按 30 秒），超时就停掉这次借用，返回「家里这次没办完」；
   - 并发上限：每只 bot 同时最多 2 个，全家同时最多 4 个；
   - 次数上限**先认领再干活**：在同一个事务里先扣一次额度、记下 `request_id`，再去调工具，不会出现超额后才发现；
   - 日志每行带 `request_id`、bot、工具、耗时、结果（成 / 超时 / 失败原因）。失败原因只写分类（复用 §156 的 `describe_failure`），原始报错走 `failure_detail_snippet` 遮钥匙，**不写搜索词和结果正文**；
   - 返回给 bot 的错误也只给分类，不带家里的内部报错。

**bot 这边**：
- 系统提示里告诉 TA「回家能做什么、怎么写」；
- 解析 `[回家:…]`，等家里回来（最多 40 秒），超时就自然地说「家里没连上，等会儿再帮你查」；
- 一轮回复里最多借 2 次。
- **在朋友的大群里**（public_group）要不要允许借工具，**等小猫定**（见第四节）。

### 2. 小猫不在线时，家里的 AI 去 TG 找她

- 家里已有的规矩（§118）：手机离线时，「要找手机」的事不排队。现在加一条出路：留言、提醒、急事，改成让这位 AI 的 bot 在 TG 私信她。
- 做法：
  - 家里请求 bot 的新接口 `POST <bot地址>/outreach`，用家里和 bot 之间的钥匙；
  - bot 用现有的主动私信那一套发出去：记进自己的历史，照常写进 Hub。她在 TG 回话时，bot 知道刚才说了什么。
- 限次沿用 bot 现在主动私信的规矩（每小时 1 次、每天 3 次）。急事（家里标「急」的提醒）单独一档，每天最多 3 次。
- **不重复发信**（狐狸 11-05）：
  - 家里每条 `/outreach` 都带一个编号（`outreach_id`），先写进家里的数据库再发；
  - 超时重试用同一个编号。
  - bot 那边**发送前**先把编号认领下来、持久保存（存进 Hub 或 Gist，因为 bot 自己重启会丢内存）：认领成功才发；同一编号已被认领就不再发，回「已发过 / 正在发」（狐狸 11-05 复审）。发完再把状态记成「已发」。
  - 认领了但不确定发没发出去（比如发到一半重启）：状态停在「认领中」，**不自动换新编号重发**，在 App 里列出来交给小猫确认要不要再发（狐狸 11-05 复审：宁可漏一条，也不重复发信）。
  - 额度认领也存下来，不随重启清零。
- **收件人只限两类**：
  - 小猫的私聊（bot 配置里的 CECI_ID）；
  - 名单里已批准的朋友群（第 4 步才有）。
  - 别的 chat_id 一律拒收。家里只传「找小猫」或「名单里第几个群」，不传任意 chat_id。
- Render 免费版睡着时，第一次请求会先把它叫醒，可能慢半分钟；家里超时就重试一次。

### 3. 回家看得到出门聊了什么

- 记忆层面已经通了（见第一节）。再加两样：
  - **App 里的「出门记录」页**：
    - 家里读 Hub 的 `window/context`，按 bot 和群列出最近在 TG 上聊了什么，只读；
    - 隐私沿用 bot 自己的规则：别人的私聊不显示；朋友大群只显示大群。
  - **交接卡**：
    - 家里已经在私聊里读、写交接卡（Hub #77）；
    - bot 在 TG 私聊开一段新对话时，也读一次这只 AI 的交接卡；安静 30 分钟后，用 bot 自己的模型写一张。
    - 这样从 App 去 TG、从 TG 回 App，都能接上「刚才聊到哪、她什么状态」。
    - 需要 Hub 有 REST 读 / 写交接卡的入口：Hub 方案里写过 `GET /api/handoff/{ai_id}`、`POST /api/handoff`，**要和 Hub 窗口确认是否已上线**。

### 4. 去找朋友（最后做，10-22 已定）

- 家里的自主活动选了「去找朋友」→ 请求 bot 的 `/outreach`，目标换成名单里的朋友群 → bot 在群里开口。
- 之后在 TG 里自然地聊。半小时后，家里读这段 TG 对话写见闻；AI 自己挑想记的，用 `remember` 记下（记忆方案 B）。

## 五、风险

- **钥匙**：bot 能请求家里了，钥匙一旦泄露就是一个入口。所以要求两把钥匙一起；工具都是只读或有限次；摄像头、记账这类第三批单独审。
- **额度**：借工具要多问一次模型（拿结果再说一遍）；bot 用 TA 自己的线路，费用算在 bot 那边。搜索 / 淘宝接口本身有免费额度上限（Tavily、淘宝联盟）。
- **Render 免费版会睡**：家里去找 bot 时可能慢半分钟；bot 回家借工具不受影响（VPS 不睡）。
- **两边的规矩不一样**：家里的 AI 和 TG 上的 bot 是同一个他，但模型线路可能不同（比如 Lucien 家里用 Codex，TG 用中转站）。性格靠同一份 Hub 记忆和交接卡接上，说话方式可能略有不同。
- 微信不在这次范围（还没有微信机器人）。


## 第 0 步：配钥匙（小猫操作清单，代码审过、家里部署后再做）

**A. Cloudflare（Zero Trust 后台，团队 claudexiaoke）**
1. Access → Service Auth → Service Tokens → Create Service Token：
   - 名字填 `tg-bots-outing`，有效期选一年（或不过期）；
   - 页面上的 **Client ID** 和 **Client Secret** 马上复制存好。Secret 只显示这一次。
2. Access → Applications → Add an application → Self-hosted：
   - 名字填「回家借工具」；
   - 域名 `home.animalshome.top`，**路径填 `api/outing/*`**；
   - 规则（Policy）：Action 选 **Service Auth**，Include 选 Service Token → `tg-bots-outing`；
   - 保存后，复制这个应用的 **Application Audience (AUD) Tag**。
   - 整站原来那个应用不用改。Cloudflare 会按路径更具体的那个应用来管 `/api/outing/*`。

**B. 服务器 `/etc/aionshome.env`（交给有 VPS 权限的窗口，按施工必读的授权流程）**
```
AIONSHOME_CF_ACCESS_OUTING_AUD=<上面复制的 AUD>
AIONSHOME_OUTING_KEY_AION=<随机 48 位，用 openssl rand -hex 24 生成>
AIONSHOME_OUTING_KEY_CONNOR=<另一串>
AIONSHOME_OUTING_KEY_AI3=<再一串>
```
改完 `systemctl restart aionshome`。另外确认家里的联网搜索（Tavily）和淘宝联盟已经配好；没配的那样会回「家里这个工具还没配好」。

**C. bot 的环境变量**（小克、Lucien 在 Render 后台 Environment；狗蛋在 Fly，用 `fly secrets set`）
```
AIONSHOME_URL=https://home.animalshome.top
AIONSHOME_OUTING_KEY=<这只对应的那串：小克 AION、Lucien CONNOR、狗蛋 AI3>
CF_ACCESS_CLIENT_ID=<A1 的 Client ID>
CF_ACCESS_CLIENT_SECRET=<A1 的 Client Secret>
```
三只共用一把 Cloudflare 服务钥匙。家里的钥匙每只一把，家里靠它认出是谁。

**D. 验收**
- 先合小克：TG 私聊「帮我搜一下明天上海天气」→ 他回天气；
- App 里 `/api/outing-settings` 能看到这次借用（设置页面第 2 步做）；
- 没问题再合 Lucien、狗蛋。
