# 点歌台网易云账号

在点歌台点「网易云」扫码，用官方客户端确认，再在点歌台确认所显示的账号。二维码由前端生成，不需要服务器浏览器。也支持在密码输入框验证已有 MUSIC_U。退出后不会重新启用设置页中的旧凭据。

支持个人歌单、红心、每日推荐、私人 FM、官方榜单和听歌排行。云歌单按50首分页；整单导入仅保存歌曲信息，播放时获取音频，不会批量下载音频。部分歌曲仍受账号会员、版权和官方验证限制。

AI 默认可整理点歌台本地歌单。网易云建歌单、加歌、红心分别需要主人在点歌台开启权限。重新登录会关闭云端写入权限；主人本人在点歌台的手动操作不受 AI 开关限制。没有删除云歌单/歌曲的接口。新建云歌单采用网易云私密值10。

聊天荐歌继续使用 `[MUSIC:歌名 歌手]`。建歌单使用独立 `MUSIC_PLAYLIST` JSON 块，由服务端验证权限、歌名、歌手和版本后执行，块本身不会显示在聊天或朗读中。支持私聊、群聊、座位及定时回复；只执行完整、非代码示例的指令。每条回复最多两个操作，每个操作最多10首歌曲。云写入绑定账号代次；本地导入在 SQLite 事务中完成。

账号凭据存入私有数据目录 `netease_account.json`，原子替换，仅公开账号标识、昵称和权限。凭据不进入模型提示词。账号接口要求点歌台自定义请求头，并检查 Origin；复用站点既有访问控制，不另开公共账号入口。新增库为静态 MIT qrcodejs，未增加服务端依赖或常驻进程。

操作编号落在原聊天数据库的 `music_station_actions` 表。网络失败或超时后保留“结果未确认”，不自动重放写入；先刷新实际歌单查看结果。已有同名自建云歌单会复用，避免超时重试产生同名新歌单。本地导入按歌曲来源编号去重，保留已手动修改的信息。

功能参考 [InternalBeyond-Mobile](https://github.com/cirel94june/InternalBeyond-Mobile)，采用本项目已有 pyncm 独立实现，未复制 IB 应用代码或视觉素材。二维码使用 [qrcodejs](https://github.com/davidshimjs/qrcodejs/tree/04f46c6a0708418cb7b96fc563eacae0fbf77674)，许可证见 `aion-chat/static/vendor/qrcode.LICENSE.txt`。

本地验证覆盖权限撤销、账号切换、二维码确认、事务回滚、同一操作并发去重、超时不重放、完整/截断指令隐藏。可选 `test_netease_browser.py` 使用隔离浏览器和假 API 检查手机尺寸界面，不登录真人账号。
