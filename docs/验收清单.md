光看代码不够：审查和部署前，要按手机尺寸（375×812）**真的打开、真的点**，并截图看效果。下面每一项都写清楚「怎么做」和「对的样子」。

## 怎么跑

- **本机（最新代码 + 测试数据）**：启动 AionsHome（`python -m uvicorn main:app --app-dir aion-chat --port 8080`），浏览器切到手机尺寸。测试数据里的模型是假的，「发消息后 AI 回复」这一项只能在服务器上验。
- **服务器（真实数据，只看不改）**：`ssh -N -L 18080:127.0.0.1:8080 root@<服务器>`，再打开 http://localhost:18080 。不经过 Cloudflare，不用登录。**不要在真实对话里发测试消息**（会进她的聊天和 Hub 记忆）；要发，先问小猫。
- **全页巡检**：在 AionsHome 任意页面的浏览器控制台运行 `tools/page_sweep.js`，等它跑完会列出每个页面有没有横向溢出、坏图、页面上的错误字样和脚本报错。

## A. 私聊（小克）

1. 打开「聊天」→ 联系人页：小克、Lucien、狗蛋都在，空位灰着；点小克的一个窗口能进去。
2. 直接打开 /chat：**自动打开最近的对话**，不能停在「选择或创建一个对话」。
3. 顶部有名字徽章（小克），标签页标题「小克 · 私聊」。
4. ⚙ 里的模型下拉：**第一个是小克自己的模型**；**不出现 Codex，也不出现别人的专属线路**（seat_ai3 之类），小克自己的 seat_aion 可以。
5. 没打开对话时直接打字发送：自动开新窗口并发出去，字不能留在框里没反应。
6. （服务器上，先问小猫）发一句：小克用他自己的模型回复；回复失败时的提示要说清原因（连不上线路 / 没有线路 / 模型拒绝），不能笼统写「连接中断」。
7. 开新窗口、改窗口名、切窗口：新窗口里小克仍记得其他窗口最近聊的。

## B. 群聊和其他人

1. 主页「群聊」：**一定进群聊**；在里面切到私聊、回主页、再点「群聊」，还是回到群聊。
2. 群聊顶部显示「群聊」，私聊显示 TA 的名字；👥 能回联系人页。
3. 手动轮流模式：小克说 / Lucien 说 / 狗蛋说 按钮都在（只列入住的）；狗蛋的回复能编辑。
4. Lucien 私聊用 Codex；狗蛋私聊用他名片里的模型；名片里没选模型时明确提示，不偷偷换别人的。
5. 开新窗口（Lucien、狗蛋）能开；主动消息去她最后说话的窗口。

## C. 设置和开关

1. 哨兵：线路和模型一致（选 Codex 时显示 Codex 模型）。
2. 免费语音试听：能出声；不能出声时要写原因。
3. 每个开关点了要有反应（保存成功 / 失败的提示），刷新后状态还在。
4. 世界书「AI 人设」：每个人都能切换、读到之前不能保存、保存失败会提示。
5. Hub 记忆：列表能出；改、归档、找回、彻底删除（二次确认）都有正确提示。

## D. 手机 App

1. 新装 App：首屏填 https://home.animalshome.top → Cloudflare 登录 → 进家。
2. 后台推送能收到；相机允许后，服务器 `/api/phone-camera/status` 显示 `armed: true`。
3. 相机没接上时，监控不刷屏（最多 6 小时提醒一次）。

## E. 每页都要看的视觉

- 手机宽度下没有横向滚动；文字不被挤扁、不叠在一起；按钮至少 44px 高。
- 深色、浅色主题下文字都看得清。
- 空位（座位 4～6）灰着、不能点。
