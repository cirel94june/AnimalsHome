# 施工方案：AI 好友改成走 TG 和微信（草稿，待小猫确认）

2026-10-22 小猫：
- 「AI 好友」包括：别人家的 TG 机器人、她的真人朋友。
- 在哪聊：TG 里已经有的群；微信里她拉 AI 进去的群。
- 会客厅（Visitor Lounge，要求对方也装同一套系统）不再用，改成 TG 和微信。

## 现状

- 会客厅：每位朋友的 AI 自己开一个 MCP「会客厅」，我们的 AI 带着地址和钥匙上门聊最多 8 轮，回来写见闻（`lounge_*`、`visitor_lounge/`、自主活动 friend_visit / board_*）。门槛高，对方必须装同一套。
- TG：小猫的三个 TG 机器人（小克 / Lucien / 狗蛋）已经在群里能看到别人家的机器人说话并接话（webhook 收到 `is_bot` 的消息，带冷却、身份识别）。在 TG 上发生的对话会写进 Memory Hub（platform=telegram），AionsHome 的 AI 通过 Hub 的「各端最近动态」能知道。
- 微信：AionsHome 接的是微信官方 ClawBot / iLink 机器人通道，现有代码只处理一对一（发给某个 user_id，要有对方发来消息时带的 context_token）。是否支持群、能否主动发起，公开资料说法不一，**需要实测**。

## 设计

### 一、好友名单（AionsHome）

「AI 好友」页改成一张名单，每位好友一条：
- 名字、是谁（别人家的 AI / 真人朋友）、关系备注（给 AI 看的）；
- 在哪：TG 群（群 id）或微信群（群 id，实测可行后）；
- 谁能去找 TA：小克 / Lucien / 狗蛋…（对应 TG 上的哪个机器人）；
- 允不允许自主去找、冷却时间（沿用原来的字段思路）。

### 二、TG（确定能做，先做）

- **主动去找**：AionsHome 的自主活动选了「去找朋友」→ 调用对应 TG 机器人的一个新接口「去某个群说一句」，带上开场白（由 AI 自己想）。之后在 TG 群里自然地聊，机器人之间本来就会互相接话（有冷却，不会刷屏）。
- **回来记得**：TG 上聊的内容照旧写进 Hub；AionsHome 这边在约定时间后（比如半小时）读 Hub 里这段 TG 对话，生成一段「去找某某聊了什么」的见闻，进家庭动态 / 日记，可选告诉小猫。
- **改两边**：
  - tg-bots：加「主动发言」接口（带鉴权，只能发到名单里的群）。需要按 tg-bots 的流程改。
  - AionsHome：名单、自主活动 friend_visit 改成走 TG、见闻生成。
- **真人朋友在 TG**：真人朋友本来就能在群里和机器人聊，不需要额外做；名单里标出来，AI 主动找时会知道对方是人。

### 三、微信群（先实测）

- 先做一个小测试：小猫把接了 ClawBot 的那个微信拉进一个测试群，看 AionsHome 能不能收到群消息、能不能在群里回话、能不能主动开口。
- 可行：和 TG 一样，名单里填群，AI 能在群里聊、能主动找。
- 只能一对一：真人朋友可以直接加这个微信和 AI 私聊（需要单独决定：谁的消息算谁、私聊内容能不能进 Hub、隐私边界）。AI 和 AI 在微信上互聊做不了。
- 不考虑非官方的微信外挂（封号风险）。

### 四、会客厅

不再作为好友入口；代码先留着不删（自主活动里 friend_visit / board_* 改成走新名单，会客厅相关开关默认关）。等新方式稳定后再决定删不删。

## 定稿的做法

### TG 机器人（tg-bots，三个仓库同样改）
1. **「主动去群里说话」接口**：`POST /api/aionshome/visit`（带共享密钥），参数：群 id、开场白、可选的「这次是去找谁」。只允许发到好友名单里的群；发出后照旧进入群聊流程（别的机器人回话、冷却、防刷屏都不变）。
2. **「用 AionsHome 工具」**：机器人在 TG 里需要用 AionsHome 才有的本事时，向 AionsHome 发请求，AionsHome 做完把结果交回，机器人在 TG 里说出来。第一批只开安全的：联网搜索、设闹铃 / 日程、记事、看监控截图描述、生图（结果发图）。涉及付款、玩具、智能家居的不开。
3. **聊完回报**：一次「找朋友」结束（一段时间没人再说话，或聊满若干轮）后，机器人把这段 TG 对话交给 AionsHome（不经过 Hub），用于写见闻和让 AI 挑重点。

### AionsHome
1. **好友名单**（替换会客厅好友页）：名字、是人还是别人家的 AI、关系备注、在哪个 TG 群、谁能去找（小克 / Lucien / 狗蛋…对应哪个 TG 机器人）、能不能自主去、冷却。
2. **自主活动「去找朋友」**改走 TG：AI 想好开场白 → 调对应机器人的 visit 接口 → 等机器人回报 → 用 AI 自己的人设写一段见闻进家庭动态，并问 AI「这次有什么想记住的」，想记的走 `remember`。
3. **工具服务**：给 TG 机器人一个带密钥的接口，按「哪个机器人 = 哪位 AI」执行工具，身份、开关、就绪检查都照 AionsHome 里的规矩。
4. 会客厅：好友入口、自主活动里的 friend_visit / board_* 改走新名单；会客厅代码先留着、开关默认关。

### 需要和 Hub 窗口对接的（写好给小猫转）
- TG 机器人在朋友群（`public_group`）capture 时已经带 `sender_type`（user / agent）和 `sender_id`。需要 Hub 确认：public_group 里别人家 AI（agent）说的话、它们的设定，提取时不会被当成小猫的事或事实；真人朋友说的事记在朋友名下。
- AI 自己挑的重点走 `remember`，speaker_name 填说这话的人（可能是朋友或朋友的 AI），subject_name 填说的是谁。需要 Hub 确认朋友（非小猫）作为 subject 时会进哪个房间（比如 people / social）。
- 不需要 Hub 新增接口；如果 Hub 大修期间这两点有变，等 Hub 通知。
