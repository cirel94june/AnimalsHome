# 台球音效替换

当前使用你提供的六个 MP3 文件，不转码、不修改音频内容。可以直接用新的 MP3 替换。保持路径和文件名不变，不需要修改代码。

| 文件名 | 对应声音 | 说明 |
| --- | --- | --- |
| ball-hit.mp3 | 球与球碰撞；音量随碰撞强度变化 | 你的当前文件 |
| pocket-drop.mp3 | 球入袋的滚动与落袋声（白球洗袋也使用） | 你的当前文件 |
| cue-hit.mp3 | 球杆击中白球；音量随击球力度变化 | 你的当前文件 |
| turn-change.mp3 | 真正换人时的短提示；同一人续杆不播放 | 你的当前文件 |
| victory.mp3 | 你赢下这一局 | 你的当前文件 |
| defeat.mp3 | 你输掉这一局 | 你的当前文件 |

1. 将替换文件放到本文件所在的 `assets/audio` 目录，覆盖对应文件。建议先备份原文件。
2. 文件需要是真正可播放的 MP3；不需要转换成 WAV。不要仅改其他音频格式的扩展名。
3. 碰撞与击球适合短声音，入袋声建议约 0.3–0.7 秒，换人约 0.2–0.4 秒，胜负约 0.7–1.5 秒。不要使用已经失真的满幅音频。
4. 保存后刷新 `index.html`（F5；必要时 Ctrl+F5），首次点击页面后即可发声。Chrome 和 Edge 的离线双击打开及同名替换均经过验证。

设置里的「音效音量」默认 35%；「静音」包含胜负音效。开球时限制叠加声音，防止过响。声音被浏览器阻止时游戏仍可运行；文件无法播放且备用音频可用时会使用简单备用音。

原始占位音效生成器已加入保护：只要存在用户 MP3 或已有 WAV 就拒绝生成，避免覆盖或重新产生重复文件。

当前占位头像在 `assets/avatar-placeholder.svg`，它是插画，不是真人照片。未来头像接入只需要替换这个本地资源或指定新的图片地址；本阶段没有小家或新 AI 集成。
