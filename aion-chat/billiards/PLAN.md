# 小家台球室接入计划

用户已确认设计并要求直接实施；在当前分支执行，不创建 worktree。

目标：独立的台球模块，任意伴侣对局、桌边聊天和主动接话、服务端保存续局、伴侣自主约球；娱乐室作为统一玩法入口。

结构：本目录包含 Python 服务、Node 算法入口、复制的网页/算法/音效、关键测试和说明。存档在小家的 data/billiards。宿主仅注册可选路由、一个自主行动入口和大厅链接。原 demo 不作为运行依赖。

约束：名字/人设使用现有配置；模型不决定击球；八球剩球与局数分别显示；已出杆先记日志再结算，动作只提交一次；人参与的局离开后暂停，双伴侣局后台继续；错误局暂停，不拖累宿主。模型慢或失败不影响算法。

任务：
- [x] 存档和算法：复制核心、实现合法动作执行、持久化状态和动作去重；验证重新加载、重复动作、失效版本、连续表现。
- [x] 球局服务：独立回合任务、控制窗口租约、暂停恢复、下一局比分、后台双算法；验证暂停、租约、恢复未结算动作。
- [x] 陪伴：最新球况和聊天注入、稀疏主动发言、邀请接受、时间线和真实战报；模型失败局部处理。
- [x] 页面和大厅：保留原操作、接入后台、聊天和保存提示，聚合斗地主/幽林/Seeky/外部探索；桌面只留娱乐室，返回大厅。
- [x] 验收：14 项关键单元测试、82 项算法与坐标测试、隔离测试服务的真实浏览器桌面/手机检查；结果见 README。
- [x] 手机性能：缓存静态球桌、静止和隐藏时跳过绘制、界面只在变化时更新；对照测量及触摸出杆回归。
- [x] 桌边语音：聊天图标旁小麦克风按住说话，复用原生录音/现有 ASR，松手发送当前对手；取消、授权延迟、页面隐藏及失败恢复检查。
- [x] 聊天隔离：桌边对话只留球局，继承日常上下文；每局胜负小卡片投递最后用户发言窗口，进入后续上下文，重试不重复。
- [x] 音效增益：台球音效放大两倍，沿用音量/静音和叠加限制。
- [x] 手机空间：头像移至桌上方，气泡向下且更透明；移除语音/力度整行，蓄力在球杆旁显示并后拉，桌边小按钮不占布局高度；触摸及语音回归。
- [x] AI 球杆同步：后端在反应等待前发布本杆选择，网页转杆和后拉，显示方向与实际击球一致；两个伴侣位置和暂停恢复检查。
- [x] 手机布局美化：头像比分合并、裁去桌外空白且顶端对齐、单色窄桌框；右下圆形蓄力，语音/聊天移至下方，成组 SVG 微调，收起常驻规则文字；触摸、语音、AI 动画及横屏/桌面验收。

验收关注：出杆过程中刷新不能撤销；两个窗口不能重复出杆；球局暂停不继续自动打；旧模型回复不能污染新局；缺 Node/模块不可用时其他页面可用。
